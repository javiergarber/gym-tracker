# Detalle del día

## Descripción
Muestra los ejercicios de un día concreto, incluyendo sus series y repeticiones. Desde aquí el usuario puede ver el histórico de cada ejercicio o comenzar el entrenamiento de ese día.

## Flujo
1. El usuario llega desde el detalle del entrenamiento pulsando un día
2. Se muestra el nombre del día (ej: "Día 1 - Pecho")
3. Se listan los ejercicios con sus series y repeticiones
4. Cada ejercicio tiene un botón o enlace "Historial"
5. Hay un botón "Comenzar" que inicia la sesión para ese día

## Acceptance Criteria
- Se muestra el nombre del día como título
- Lista de ejercicios ordenados según el orden del CSV
- Cada ejercicio muestra: nombre, series × repeticiones (ej: "Press banca: 4×10")
- Cada ejercicio tiene un botón "Historial" que navega al historial de progresión
- Botón "Comenzar" que inicia la sesión desde el primer ejercicio de ese día
- Se puede volver atrás al detalle del entrenamiento
