# Temas configurables

## Descripción
El usuario puede cambiar entre dos temas de color disponibles: Morado-Negro-Neón y Azul-Teal. El cambio se aplica instantáneamente a toda la interfaz y persiste entre sesiones.

## Temas disponibles
- **Morado-Negro-Neón**: fondo oscuro, morado como color principal, verde neón como acento
- **Azul-Teal**: fondo oscuro, azul claro como color principal, teal como acento

## Flujo
1. El usuario navega a la pantalla de Ajustes
2. Ve la sección "Tema" con dos opciones visuales
3. Selecciona uno de los temas
4. La interfaz se actualiza instantáneamente con los nuevos colores
5. La selección se guarda y se restaura al abrir la app nuevamente

## Acceptance Criteria
- En Ajustes hay una sección "Tema" con dos opciones seleccionables
- Cada opción muestra una previsualización o los colores representativos
- Al seleccionar un tema, toda la interfaz cambia de color inmediatamente
- El tema seleccionado persiste al cerrar y reabrir la aplicación
- Los textos y elementos mantienen buen contraste y legibilidad en ambos temas
- La selección se guarda automáticamente sin necesidad de botón "Guardar"
